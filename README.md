Proyecto: Aplicaciones Web 2

Integrantes: Federico Luján, Fabricio Giménez

Tema: Rotisería “Como en Casa”

Descripción del proyecto:
Este proyecto consiste en el desarrollo de un sistema web de ventas para la rotisería “Como en Casa”. Su objetivo es reemplazar el registro manual de pedidos y pagos por una solución digital que permita organizar y gestionar la información de manera más eficiente.

El sistema permitirá registrar ventas, almacenar datos de clientes de forma opcional y consultar el estado de cada operación, mejorando así el control del negocio y la calidad del servicio.
